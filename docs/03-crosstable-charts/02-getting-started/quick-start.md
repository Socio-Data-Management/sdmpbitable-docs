# Quick Start

CrossTable InCell Charts is configured exactly like the other SDM table visuals: same data roles, same series, same Format pane cards. The only difference is how the cells are drawn.

1. **Add the visual** to your report (*Get more visuals* → **SDM CrossTable InCell Charts**).
2. **Build the table** by following the [CrossTable Quick Start](../../04-crosstable-legacy/02-getting-started/quick-start.md): rows, columns, a percentage or mean series and, if needed, a base.
3. **Choose the in-cell chart** in the Format pane:
   - [Data Bar](../04-reference/data-bar.md) — a diverging bar per cell;
   - [Data Line](../04-reference/data-line.md) — a point per cell, connected across columns;
   - [Gap Mode](../04-reference/gap-mode.md) — a column group collapsed into "main vs. reference" gap columns.
4. **Follow a tutorial**: [Gap Mode](../03-use-cases/tutorial-gap-mode.md) or [Header logos](../03-use-cases/tutorial-header-logos.md).

For the features common to all table visuals, see the [Overview](../01-introduction/overview.md) and [Common Settings](../../05-common-settings/global-threshold.md).
