# Installation Guide

## Prerequisites

Before installing SDM Xtended Table, ensure you have:

- **Power BI Desktop** (latest version) or **Power BI Service**
- Administrator or advanced permissions in your Power BI workspace
- Network access to download the visual (if using Power BI Service)

## Installation Steps

### Option 1: From Power BI Desktop

1. Open **Power BI Desktop**
2. Go to the **Visualizations** pane (right sidebar)
3. Click the **three dots** (...) at the bottom
4. Select **Get more visuals**
5. Search for **"SDM Xtended Table"**
6. Click **Add**
7. Accept the permissions dialog

The visual is now ready to use in your Power BI reports.

### Option 2: From Power BI Service (Online)

1. Open **Power BI Service** (app.powerbi.com)
2. Go to **Visualizations** → **More visuals** (or the store icon)
3. Search for **"SDM Xtended Table"**
4. Click **Add**
5. Review and accept permissions

### Option 3: Upload from File (Enterprise)

If you have a `.pbiviz` file:

1. In Power BI Desktop, go to **Visualizations** → **More visuals** → **Import from file**
2. Select your `SDM Xtended Table.pbiviz` file
3. Click **Open**

## Verification

To verify the installation:

1. Create a new blank report
2. In the **Visualizations** pane, look for the **SDM Xtended Table** icon
3. You should see it under "Custom Visuals"

✅ Installation complete!

## Troubleshooting

### Visual doesn't appear in visualizations

- **Solution 1**: Refresh Power BI Desktop (Ctrl+Shift+F5)
- **Solution 2**: Try importing from file if available
- **Solution 3**: Check your Power BI version (must be recent)

### "Insufficient permissions" error

- Contact your Power BI administrator

### Visual crashes or doesn't load data

- Check Power BI version compatibility
- Clear browser cache (if using Power BI Service)
- Try creating a new blank report

## Using it next to the other visuals

SDM Xtended Table is a **separate visual** from [CrossTable](../../02-getting-started/installation.md) and [CrossTable InCell Charts](../../05-crosstable-charts/overview.md). It is installed independently, and all of them can live in the same report. Reports built with CrossTable are not converted automatically: add the Xtended Table visual and re-assign the fields.
