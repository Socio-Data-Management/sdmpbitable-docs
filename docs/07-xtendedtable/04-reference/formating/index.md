# Formatting & Styling Overview

Customize the appearance of your table to match your brand, improve readability, and highlight key insights.

## Four Levels of Formatting

SDM Xtended Table provides flexible formatting options organized into four levels:

### 1. **Table Options** (Basic Display)
Control how the table behaves and displays, including hover effects, row striping, freezing, row spacing and column header visibility.

👉 [Table Options Reference →](formatting-basics.md)

**Key settings**:
- Hover highlights
- Zebra striping
- Freeze panes
- Row height and row group spacing
- Display precision

### 2. **Table Style Options** (Predefined Themes)
Apply pre-configured professional themes with coordinated color palettes and styling.

👉 [Table Style Options Reference →](formatting-styles.md)

**Key settings**:
- Style theme selection
- Color theme selection
- Cell text size
- Row title alignment
- Transparent background

### 3. **Tile Mode & Spacing** (Card-Like Rendering)
Turn cells into detached tiles with rounded corners, shadows, configurable padding and column/row gaps. Works with any theme.

👉 [Tile Mode Reference →](formatting-tile-mode.md)

**Key settings**:
- Tile mode toggle
- Border radius and drop shadow
- Horizontal / vertical padding
- Tile width (auto-equalize or explicit)
- Column gaps (group, sub-group), sub-cell gap, row gap

### 4. **Custom Element Formatting** (Advanced Customization)
Fine-tune fonts, colors, and backgrounds. **Data cells** are styled through the *Cell format* card; **column and row headers** are styled level by level through the ⚙ editors of the *Table Headers* card — with no limit on the number of levels.

👉 [Custom Element Formatting Reference →](formatting-custom.md)
👉 [Table Headers Reference →](../table-headers.md)

**Key settings**:
- Cell styling (any theme, via override toggle)
- Per-level header colors, fonts and logos (any number of column and row levels)
- Row layout per level (side column or full-width banner)
- Font families, sizes, weights
- Custom colors and backgrounds

## Formatting Workflow

```
1. Choose a Style Theme
   ↓
2. Adjust Table Options for behavior
   ↓
3. (Optional) Enable Tile Mode for card-like rendering
   ↓
4. Fine-tune cells (Cell format) and headers (Table Headers ⚙ editors)
   ↓
5. Test and iterate
```

---

## Best Practices

1. **Start with a Theme**: Use predefined styles as a base
2. **Maintain Consistency**: Keep formatting consistent across reports
3. **Prioritize Readability**: Clear data > beautiful design
4. **Test Accessibility**: Ensure sufficient color contrast
5. **Consider Export**: Some colors/fonts may change in Excel
